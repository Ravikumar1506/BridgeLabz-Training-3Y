Box-Sizing Comparison

Default Box

This box uses the default content-box sizing. Padding and border are added outside the given width.

Border Box

This box uses border-box sizing. Padding and border are included inside the given width.

How Box-Sizing Works

With content-box, the declared width applies only to the content. Padding and border increase the total size.

With border-box, the declared width includes the content, padding and border.
