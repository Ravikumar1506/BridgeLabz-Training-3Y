Responsive Design Principles

Core concepts for creating responsive websites

Fluid Layouts

Fluid layouts use flexible sizes so the content adjusts according to the screen width. 

.container {
    width: 90%;
    margin: auto;
}

Flexible Media

Flexible media allows images and videos to fit inside their containers without overflowing. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints change the layout when the screen reaches a specific size. 

@media (max-width: 600px) {
    .box {
        width: 100%;
    }
}
