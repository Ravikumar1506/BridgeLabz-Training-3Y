Responsive Design

Responsive web design makes a website adjust according to the screen size of the device.

CSS Flexbox, Grid and Media Queries are commonly used to create responsive websites.

A responsive website works properly on desktop, tablet and mobile devices.

CSS Cheat Sheet

Flexbox Used for alignment and navigation.
Grid Used for rows and columns.
Media Query Changes styles for different screens.
Clamp Creates responsive text sizes.
